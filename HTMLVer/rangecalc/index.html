Standard RangeCalc

A modern, offline-capable Progressive Web App for calculating range to a target using two compass bearings. Supports Simple Mode and Full Triangulation using the Law of Sines.

  • ✔️ Classic cotangent + Law of Sines
  • ✔️ Baseline bearing input
  • ✔️ Calculation history
  • ✔️ Dark/Light mode
  • ✔️ Fully offline PWA
📍 GPS + Map

RangeCalc + GPS

Powerful version with GPS integration and interactive map. Automatically capture locations, calculate baseline distance/bearing, and visualize results on a Leaflet map.

  • ✔️ GPS location capture
  • ✔️ Interactive Leaflet Map
  • ✔️ Target verification
  • ✔️ Baseline auto-calculation
  • ✔️ Fully offline PWA

Both versions are offline-capable PWAs • Made for field use, surveying & outdoor activities
